# คลังคลิป

คลังวิดีโอขายสินค้าสั้น ๆ — สมาชิกแต่ละคนมีบัญชีของตัวเอง เชื่อม TikTok / Facebook เพจ / Instagram
เลือกคลิปจากคลัง ตั้งวัน-เวลา แนบลิงก์ร้านค้า (และรหัสสินค้าปักตะกร้า TikTok) แล้วระบบโพสต์ให้ตามเวลา

## รัน

```bash
SEED_CLIP=/path/to/clip.mp4 node server.js     # SEED_CLIP ไม่บังคับ ใช้ใส่คลิปตัวอย่างครั้งแรก
# เปิด http://localhost:3000   แอดมินเริ่มต้น: admin@klangklip.local / admin1234 (โหมดทดลองเท่านั้น)
npm test                                        # ต้องมี SAMPLE_VIDEO=ไฟล์.mp4 ถ้าอยากทดสอบอ่านขนาด/ภาพปก
node test/failure.mjs                           # ทดสอบเส้นทางล้มเหลว/ลองใหม่
node test/facebook.mjs                          # ทดสอบสาย Facebook ทั้งหมดกับ Graph API จำลอง
node test/captions.mjs                          # ทดสอบปุ่มสร้างแคปชันด้วย AI กับ API จำลอง
```

ต้องใช้ Node 20+ ไม่มี dependency และถ้ามี `ffmpeg`/`ffprobe` ในเครื่อง ระบบจะทำภาพปกและอ่านความยาวคลิปให้อัตโนมัติ

| ตัวแปร | ความหมาย |
|---|---|
| `PORT` | พอร์ต (3000) |
| `DATA_DIR` | โฟลเดอร์ข้อมูล (`data/`) เก็บ db.json, วิดีโอ, กุญแจเข้ารหัส |
| `PLATFORM_MODE` | `mock` (ค่าเริ่มต้น จำลองการโพสต์) หรือ `live` |
| `ADMIN_EMAIL` / `ADMIN_PASSWORD` | แอดมินเริ่มต้น (โหมด live ต้องตั้ง `ADMIN_PASSWORD`) |
| `TOKEN_KEY` / `SESSION_KEY` | hex 32 ไบต์ ถ้าไม่ตั้งจะสร้างไฟล์ใน `data/` |
| `COOKIE_SECURE=1` | ตั้งเมื่อรันหลัง HTTPS |
| `FB_APP_ID` / `FB_APP_SECRET` / `FB_REDIRECT_URI` | แอป Facebook (ใช้เมื่อ `PLATFORM_MODE=live`) |
| `FB_GRAPH_VERSION` | เวอร์ชัน Graph API (ค่าเริ่มต้น `v23.0` — ตรวจว่ายังรองรับอยู่) |

## สร้างแคปชันด้วย AI

ปุ่ม "✨ สร้างแคปชันด้วย AI" อยู่ในหน้าตั้งเวลา (เมื่อเลือกคลิปเดียว) และหน้าแก้ไขคลิปของแอดมิน
ระบบส่งเฟรม 3 ภาพจากคลิป + ชื่อ/สินค้า/แคปชันเดิม ไปให้ Claude เขียนแคปชันไทย 3 แบบ ให้ผู้ใช้เลือกแล้วแก้ต่อ
ตั้ง `ANTHROPIC_API_KEY` ที่เซิร์ฟเวอร์ (คีย์ไม่ถูกส่งไปหน้าเว็บ) ไม่ตั้ง: โหมดทดลองได้ตัวอย่างจำลอง, โหมด live ปิดปุ่ม
คิดค่า API ตามการใช้งานจริง จำกัดต่อสมาชิกด้วย `AI_CAPTION_LIMIT_PER_HOUR` (ค่าเริ่มต้น 30)
AI ถูกสั่งไม่ให้อ้างสรรพคุณทางการแพทย์/รับประกันผล แต่ **ผู้ใช้ต้องอ่านทวนก่อนโพสต์เสมอ** โดยเฉพาะสินค้าอาหารเสริม

## ตั้งค่า Facebook Reels (โพสต์ลงเพจจริง)

1. สร้างแอปที่ developers.facebook.com (ประเภท Business) เพิ่มผลิตภัณฑ์ **Facebook Login for Business**
2. ใส่ Valid OAuth Redirect URI = `https://โดเมนของคุณ/api/oauth/facebook/callback` (ต้องเป็น HTTPS ตอนใช้จริง)
3. ขอสิทธิ์ `pages_show_list`, `pages_read_engagement`, `pages_manage_posts`, `publish_video`
   — ระหว่างที่แอปยังเป็นโหมด Development ใช้ได้กับแอดมิน/เทสเตอร์ของแอปและเพจที่พวกเขาดูแลเท่านั้น
   ถ้าจะให้สมาชิกทั่วไปเชื่อมเพจ ต้องส่งแอปรีวิว (App Review) และยืนยันธุรกิจ
4. รัน: `PLATFORM_MODE=live ADMIN_PASSWORD=... FB_APP_ID=... FB_APP_SECRET=... FB_REDIRECT_URI=... COOKIE_SECURE=1 node server.js`
5. สมาชิกเข้า "บัญชีของฉัน" → "เชื่อมด้วย Facebook" → เลือกเพจ

ข้อกำหนดคลิป Reels: แนวตั้ง 9:16, ขั้นต่ำ 540×960, ยาว 3–90 วินาที (ระบบตรวจตอนตั้งเวลา)

พฤติกรรมเมื่อพลาด: โทเคนหมดอายุ/สิทธิ์ไม่พอ → ล้มเหลวทันทีและติดป้าย "ต้องเชื่อมใหม่"; rate limit → ลองใหม่ได้ 3 ครั้ง;
หลัง Facebook รับงานแล้ว (สั่ง finish สำเร็จ) จะ **ไม่ลองซ้ำ** เพื่อกันโพสต์ซ้ำ

## โครงสร้าง

- `lib/store.js` — ที่เก็บข้อมูลทั้งหมดผ่านไฟล์นี้ที่เดียว (ไฟล์ JSON) → สลับเป็น Firestore ได้โดยแก้ไฟล์เดียว
- `lib/security.js` — รหัสผ่าน scrypt, เข้ารหัสโทเคนโซเชียล AES-256-GCM, ลงนามเซสชัน
- `lib/platforms.js` — ตัวโพสต์ต่อแพลตฟอร์ม (ตอนนี้มีเฉพาะ mock) + ประกอบแคปชัน
- `lib/worker.js` — ตรวจคิวทุก 10 วินาที ลองใหม่สูงสุด 3 ครั้ง (เว้น 5 นาที) แล้วทำเครื่องหมายล้มเหลว
- `server.js` — API + ไฟล์หน้าเว็บ + สตรีมวิดีโอ (รองรับ Range)

## สิ่งที่ยังไม่ได้ทำ

1. **Facebook ยังไม่เคยทดสอบกับ Facebook จริง** — ทดสอบกับ Graph API จำลองเท่านั้น ลองกับเพจของตัวเองก่อนเปิดให้สมาชิกใช้ และตรวจเอกสาร Reels Publishing API ว่าตรงกับโค้ดใน `lib/facebook.js`
2. **TikTok** — Content Posting API (แอปที่ยังไม่ผ่านรีวิวโพสต์ได้แบบส่วนตัวเท่านั้น) ตอนนี้บัญชีจริงของ TikTok ล้มเหลวพร้อมข้อความ "ยังไม่รองรับ"
3. **Instagram** — ต้องเป็นบัญชีธุรกิจ/Creator ที่ผูกกับเพจ และวิดีโอต้องมี URL สาธารณะให้ Meta ดึง (ยังไม่ได้ทำ)
4. **ปักตะกร้า TikTok** — ช่องรหัสสินค้าเก็บลงคิวแล้ว แต่ต้องตรวจเอกสาร TikTok Shop ว่า API แนบสินค้าตอนโพสต์ได้หรือไม่ ถ้าไม่ได้ต้องปักด้วยมือหลังโพสต์
5. **ย้ายไป Next.js + Firebase** (ถ้าต้องการ) — เครื่องที่สร้างติดตั้งแพ็กเกจไม่ได้ จึงเขียนด้วย Node ล้วน
6. **เก็บไฟล์วิดีโอ** — ตอนนี้อยู่ในดิสก์เครื่อง ถ้าคลังโตควรย้ายไป Cloud Storage/S3
